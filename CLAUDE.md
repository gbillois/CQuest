# CQuest - Instructions projet

## Architecture multi-plateforme

Ce projet contient **deux versions** du jeu :

1. **Version Web (HTML/JS/CSS)** - à la racine du projet (`index.html`, `src/`, `styles.css`, etc.)
2. **Version iOS native (Swift)** - dans le dossier `ios-native/`

## Règle importante

Sauf contre-ordre explicite, **toute modification demandée doit être appliquée sur les deux plateformes** (Web et iOS).
